= Release Notes Kotlin Extension
:navtitle: Release notes

You can find the release notes for the Kotlin Extension of version 4.10.0 and above below.
For earlier releases, please visit the link:https://legacydocs.axoniq.io/reference-guide/release-notes/rn-extensions/rn-kotlin[legacy documentation].

== Release 5.0.0

=== _Enhancements_

- Upgraded to Axon Framework 5.0.x and JVM 21
- Replaced `CommandCallback`-based API with `CommandResult`; new extensions: `send`, `sendForResult`, `sendAndWait`
- Replaced `ResponseType`-based query extensions with direct-typed variants: `query`, `queryMany`, `subscriptionQuery`, `streamingQuery`
- Replaced `AggregateTestFixture` / `SagaTestFixture` with phase-based `AxonTestFixture` API; new extensions: `whenever`, `exception`
- Removed `EventUpcaster` Kotlin DSL (removed in Axon Framework 5)
- Removed `ArrayResponseType`, `AggregateLifecycleExtensions`, `BuilderExtensions`, `ResultDiscriminatorCommandCallback` (all removed in Axon Framework 5)
- Updated artifact dependency from `axon-configuration` to `axon-messaging`

== Release 4.10.0

Upgrades the Kotlin Extension to be compatible with Axon Framework 4.10.0.
This adds a serializer with `kotlin.serialization` support. See the link:https://github.com/AxonFramework/extension-kotlin/releases/tag/axon-kotlin-4.10.0[GitHub release notes] for an exhaustive list of all changes.
